What Teltonika actually published

The search for an automated firmware and config update leads to a March 2026 community thread. Support’s recipe is a task group plus a script on every router. Rutkeeper keeps that sequence here instead.

  1. GET /firmware/device/updates/status Stop when stable_version is newest.
  2. Device backup Support used sysupgrade -b before an upgrade. The file is stored on this Pi, not only on the router.
  3. POST /firmware/actions/fota_download {"data": {"type": "stable"}}
  4. POST /firmware/actions/upgrade {"data": {"suppress_validation": 1, "keep_settings": 1}} when keep-settings is on.

Config rollout is a backup pushed to routers with the same product code and the same or older firmware than the file. RMS can do the same from the cloud; the RMS page fires that task group from here if the routers are not on this LAN.
